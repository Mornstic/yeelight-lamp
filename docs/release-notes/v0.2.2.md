# Yeelight 屏幕挂灯 v0.2.2

修复一个轮询节奏问题：面板重新打开后，后台还会沿用收起时的 20 秒间隔，导致自动补光的亮度、色温要关闭面板再打开才显示。现在面板一显示就会唤醒轮询，2.5 秒内跟上灯体变化。

## 下载

| 文件 | 大小 | 说明 |
| --- | ---: | --- |
| `yeelight-lamp_0.2.2_x64-setup.exe` | 2.51 MB | 推荐；当前用户安装，无需管理员权限 |
| `yeelight-lamp_0.2.2_x64-portable.zip` | 3.20 MB | 免安装，解压后运行 `yeelight-lamp.exe` |
| `SHA256SUMS.txt` | < 1 KB | SHA-256 校验和 |

系统要求：Windows 10 / 11，WebView2 运行时（Windows 11 已自带）。

## 本次更新

### 修复

- 面板重新打开后会立即切回 2.5 秒轮询，不再等完收起时的 20 秒睡眠
- 点击自动补光后，灯体自行调整的亮度和色温会自动出现在面板上，不需要关闭再打开

### 工程

- 窗口显示时通过 `Notify` 唤醒轮询任务，保证面板刚打开时的外部变化也能及时反映

## 安装

1. 下载并运行 `yeelight-lamp_0.2.2_x64-setup.exe`
2. 已安装旧版本的用户直接覆盖安装即可，本机设置与设备 token 会保留
3. 点击托盘图标打开面板；关闭面板后程序仍驻留托盘

## 已知限制

- 仅适配 `yeelink.light.lamp43`（Yeelight 智能屏幕挂灯 2 / Tube Plus2）
- 挂灯仅支持 2.4GHz 的 WPA2 / WPA3 网络，不支持 802.1X
- 安装包暂未做代码签名，Windows SmartScreen 可能提示「未知发布者」；可核对下方 SHA-256 后继续
