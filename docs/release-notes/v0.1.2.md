# Yeelight 屏幕挂灯 v0.1.2

修复挂灯离线时反复闪出控制台窗口的问题。

![Yeelight 屏幕挂灯](https://raw.githubusercontent.com/Mornstic/yeelight-lamp/main/docs/screenshots/hero.png)

## 下载

| 文件 | 大小 | 说明 |
| --- | ---: | --- |
| `yeelight-lamp_0.1.2_x64-setup.exe` | 2.48 MB | 推荐；当前用户安装，无需管理员权限 |
| `yeelight-lamp_0.1.2_x64-portable.zip` | 3.16 MB | 免安装，解压后运行 `yeelight-lamp.exe` |
| `SHA256SUMS.txt` | < 1 KB | SHA-256 校验和 |

系统要求：Windows 10 / 11，WebView2 运行时（Windows 11 已自带）。

## 本次更新

### 修复

- 挂灯离线后，后台重连会反复执行 `arp -a` 查找设备；该子进程现在以隐藏窗口启动，不再在桌面上闪出黑色控制台窗口
- 自动重连、DHCP 换 IP 后的 ARP 发现逻辑保持不变

## 安装

1. 下载并运行 `yeelight-lamp_0.1.2_x64-setup.exe`
2. 已安装 v0.1.1 的用户直接覆盖安装即可，本机设置与设备 token 会保留
3. 点击托盘图标打开面板

## 已知限制

- 仅适配 `yeelink.light.lamp43`（Yeelight 智能屏幕挂灯 2 / Tube Plus2）
- 挂灯仅支持 2.4GHz 的 WPA2 / WPA3 网络，不支持 802.1X
- 安装包暂未做代码签名，Windows SmartScreen 可能提示「未知发布者」；可核对下方 SHA-256 后继续
