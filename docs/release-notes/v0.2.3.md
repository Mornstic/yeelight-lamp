# Yeelight 屏幕挂灯 v0.2.3

自动补光现在会记住你的偏好。以前灯关掉后固件会清掉补光，重新开灯就回到手动亮度；现在在应用里关灯再开灯，会自动恢复补光，重启应用也不会丢。

系统要求：Windows 10 / 11，WebView2 运行时（Windows 11 已自带）。

## 本次更新

### 改进

- 自动补光改为记住用户偏好：在应用里关灯再开灯，会自动恢复补光；重启应用后偏好也会保留
- 灯关着时打开补光，开关保持打开并提示「开灯后自动调节」，下次通过应用开灯时生效
- 手动调亮度、色温或切换模式，或在米家里关闭补光，偏好会同步关闭，不会擅自恢复
- 通过灯体或断电重新开灯不会自动恢复补光，开关会跟随灯的实际状态关闭

### 工程

- `settings.json` 增加 `autoFill` 偏好；快照区分 `autoFill`（偏好）和 `autoFillActive`（灯体实际状态）
- 开灯恢复补光后加入短暂宽限期，避免轮询读到旧属性时误判用户已退出

## 安装

1. 下载并运行 `yeelight-lamp_0.2.3_x64-setup.exe`
2. 已安装旧版本的用户直接覆盖安装即可，本机设置与设备 token 会保留
3. 点击托盘图标打开面板；关闭面板后程序仍驻留托盘

## 已知限制

- 仅适配 `yeelink.light.lamp43`（Yeelight 智能屏幕挂灯 2 / Tube Plus2）
- 挂灯仅支持 2.4GHz 的 WPA2 / WPA3 网络，不支持 802.1X
- 安装包暂未做代码签名，Windows SmartScreen 可能提示「未知发布者」；可核对下方 SHA-256 后继续
