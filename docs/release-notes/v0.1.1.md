托盘图标重绘、面板开合动画，以及更顺手的托盘开关。

系统要求：Windows 10 / 11，WebView2 运行时（Windows 11 已自带）。

## 本次更新

### 托盘图标

- 重绘三态图标：灯管悬浮在显示器上边框之上，中央卡扣连接，不再像机身顶盖
- 灯管、卡扣与屏幕统一对齐光学中心，深浅任务栏各一套配色，16 px 下轮廓依然清晰
- 开灯为暖色灯管与屏幕顶部的暖光，关灯为中性灰，离线为带透明挖环的珊瑚红点

### 面板

- 新增开合动画：打开时淡入并轻微上浮，收起时收缩淡出，时长约 180 ms
- 左键单击托盘图标现在可以打开或收起面板，不再只能打开
- 点击面板外部或按 `Esc` 收起时同样播放退场动画
- 修复关闭动画过程中再次点击托盘导致状态不同步的问题

## 安装

1. 下载并运行 `yeelight-lamp_0.1.1_x64-setup.exe`
2. 已安装 v0.1.0 的用户直接覆盖安装即可，本机设置与设备 token 会保留
3. 点击托盘图标打开面板

## 已知限制

- 仅适配 `yeelink.light.lamp43`（Yeelight 智能屏幕挂灯 2 / Tube Plus2）
- 挂灯仅支持 2.4GHz 的 WPA2 / WPA3 网络，不支持 802.1X
- 安装包暂未做代码签名，Windows SmartScreen 可能提示「未知发布者」；可核对下方 SHA-256 后继续
