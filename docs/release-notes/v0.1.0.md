# Yeelight 屏幕挂灯 v0.1.0

首个公开版本：把 Yeelight 智能屏幕挂灯 2（Tube Plus2）的控制留在局域网。

## 下载

| 文件 | 大小 | 说明 |
| --- | ---: | --- |
| `yeelight-lamp_0.1.0_x64-setup.exe` | 2.48 MB | 推荐；当前用户安装，无需管理员权限 |
| `yeelight-lamp_0.1.0_x64-portable.zip` | 3.16 MB | 免安装，解压后运行 `yeelight-lamp.exe` |
| `SHA256SUMS.txt` | < 1 KB | SHA-256 校验和 |

系统要求：Windows 10 / 11，WebView2 运行时（Windows 11 已自带）。

## 本次更新

### 本地直连

- 通过 miIO（UDP 54321，AES-128-CBC）直接控制灯体，不经过云端
- 自动发现设备、断线重连；设备换 IP 后无需重新配置

### 控制

- 开关、亮度 1–100%、色温 2700–6500K，拖动即时写入
- 关灯状态下调节亮度或色温会先开灯再写值
- 办公 / 专注 / 阅读 / 休闲四档场景，手动调节后回到「自定义」
- 自动补光，开启后回读灯体真实状态；手动调节会自动退出补光
- 全局快捷键：`Ctrl+Alt+L` 开关灯，`Ctrl+Alt+↑` / `Ctrl+Alt+↓` 调节亮度（默认关闭）

### 桌面体验

- 托盘三态图标：开灯、关灯、离线，随深色 / 浅色任务栏切换
- 玻璃面板与品牌化安装向导
- 单实例、开机自启（默认开启）、设置持久化

## 安装

1. 下载并运行 `yeelight-lamp_0.1.0_x64-setup.exe`
2. 首次使用时，按 README 的「首次连接」为灯组网并写入 token
3. 点击托盘图标开始控制

升级时直接覆盖安装即可，本机设置与 token 会保留。

## 已知限制

- 仅适配 `yeelink.light.lamp43`（Yeelight 智能屏幕挂灯 2 / Tube Plus2）
- 挂灯仅支持 2.4GHz 的 WPA2 / WPA3 网络，不支持 802.1X
- 安装包暂未做代码签名，Windows SmartScreen 可能提示「未知发布者」；可核对下方 SHA-256 后继续
